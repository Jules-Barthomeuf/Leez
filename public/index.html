Méthode RAG (recherche puis génération ancrée sur le texte réel du document) : chaque donnée est extraite du texte source puis vérifiée automatiquement par recoupement avec celui-ci — contrairement à un chatbot IA classique, qui peut répondre sans lien garanti avec vos documents. Le modèle est utilisé ici de façon spécialisée pour l'immobilier et l'investissement : au-delà de la simple extraction, il mobilise ce contexte sectoriel pour signaler les points qui méritent l'attention de l'analyste.

Comment ces critères deviennent des tests

APPLIQUÉS TELS QUELS, DÉTERMINISTES, À CHAQUE DOSSIER
Taille du deal — le prix demandé cité dans le document est comparé à la fourchette min/max. Prix non extrait → test « indéterminé », jamais un verdict par défaut.
Typologie — le type d'actif cité doit contenir l'une de vos typologies (comparaison de texte, insensible à la casse).
Localisation — correspondance textuelle approximative sur adresse, code postal/ville et sous-marché cités. C'est un test de texte, pas une géolocalisation.
Rendement cible — comparé au taux de capitalisation recalculé par Leez (loyers réels de l'état locatif ÷ prix), pas au rendement affiché par le vendeur.
